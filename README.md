# Tournament
Telegram bot and site for tournaments (sample: https://openffa2025.q2nn.ru/ , https://quake2.com.ru/ffa2025.php)


The repository also contains the current bilingual Q2PRO-X website, HTML/PDF history book, Mapgen Studio page and BotStats navigation. See [PUBLICATION.md](PUBLICATION.md) for the source layout, local setup and files excluded from publication.
