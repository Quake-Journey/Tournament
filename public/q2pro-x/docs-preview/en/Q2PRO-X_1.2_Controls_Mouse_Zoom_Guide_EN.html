Q2PRO-X 1.2: controls, mouse, and zoom

This guide helps tune controls in Q2PRO-X 1.2, especially when importing an

older q2pro, r1q2, or mixed cfg.

1. Where to find the menu

Guided menu:

  • Options -> Controls / Mouse;
  • Options -> Movement;
  • Options -> Weapon Predicts.

Classic Q2PRO-X menu:

  • Q2PRO-X -> mouse & zoom;
  • Q2PRO-X -> movement;
  • Q2PRO-X -> weapon predicts.

2. Main new concept: mouse behavior mode

cl_mouse_behavior_mode selects the overall mouse semantics:

  • q2pro - default Q2PRO-X behavior;
  • r1q2 - compatibility behavior for older r1q2 cfg files.

This is not just a cosmetic toggle. It affects how older variables are

interpreted and how the mouse feels after importing cfg.

If you start clean with Q2PRO-X:

  • keep q2pro.

If you import an old r1q2 cfg:

  • try r1q2;
  • check sensitivity, m_pitch, m_yaw;
  • tune zoom separately.

3. Base mouse cvars

  • sensitivity - main multiplier;
  • m_pitch - vertical gain, negative value inverts Y;
  • m_yaw - horizontal gain;
  • m_accel - Q2PRO-X mouse acceleration, no effect in r1q2 mode;
  • m_filter - smooth delta by averaging with the previous frame;
  • m_autosens - non-zoom FOV-proportional scaling;
  • freelook - always-on mouse look.

Recommended import order:

  1. Choose cl_mouse_behavior_mode.
  2. Tune sensitivity.
  3. Check m_pitch / m_yaw.
  4. Only then touch acceleration, autosens, and zoom.

4. m_autosens

m_autosens is not zoom sensitivity. It is non-zoom FOV-based scaling for

normal view movement.

Values:

  • 0 - off;
  • 91..179 - base FOV for scaling;
  • any other non-zero value - base FOV 90.

If you do not know why you need it, keep it 0. Most players should tune zoom

through the dedicated cl_zoom_* cvars instead.

5. Zoom FOV

Main cvar:

  • cl_zoom_fov.

It sets horizontal FOV while +zoom is held. The value is clamped so it never

exceeds the live base FOV: zoom should zoom in, not out.

Bind:

  • +zoom - hold zoom;
  • -zoom - release zoom.

The menu row Hold: zoom lets you bind the key.

6. Zoom sensitivity

Zoom sensitivity has two modes:

  • cl_zoom_sensitivity_mode auto;
  • cl_zoom_sensitivity_mode manual.

Auto

Auto uses a tangent-space FOV ratio. This is the geometrically correct model:

as FOV narrows, sensitivity scales with the changed view angle.

This is the recommended default for most players.

Manual

Manual uses:

  • cl_zoom_sensitivity.

This is an absolute sensitivity value in the same units as sensitivity. Use

manual only when you want a specific familiar number.

7. Zoom time

cl_zoom_time sets transition duration in seconds.

  • 0 - instant zoom;
  • 0.05..0.20 - fast but visible transition;
  • higher values - cinematic feel, usually not for competitive play.

FOV and sensitivity share the same transition so they do not desync.

8. Walk while zoomed

cl_zoom_walk holds +speed together with +zoom.

Use it if you want to slow down automatically while zoomed. It coexists with a

normal +speed bind.

Default is off.

9. Zoom crosshair

Separate zoom crosshair:

  • cl_zoom_crosshair_enable;
  • cl_zoom_crosshair;
  • cl_zoom_ch_scale;
  • cl_zoom_ch_health;
  • cl_zoom_ch_red;
  • cl_zoom_ch_green;
  • cl_zoom_ch_blue;
  • cl_zoom_ch_alpha.

If the master is off, the normal crosshair remains visible while zoomed.

Practical setup:

  • cl_zoom_crosshair_enable 1;
  • style dot or cross;
  • alpha 0.7..1.0;
  • color by health off if you want a stable color.

10. Movement feel

Related cvars:

  • cl_movement_feel_mode;
  • cl_predict_move_mode;
  • cl_step_smoothing_mode;
  • cl_fixedmove;
  • cl_predict_player.

If you want an r1q2-like feel, check:

  • mouse behavior = r1q2;
  • movement feel = r1q2-like;
  • step smoothing r1q2 profile;
  • fixedmove to taste.

Command:

  • movementfeel_info.

It prints the resolved movement feel state and helps compare cfg profiles.

11. Binds

Useful actions:

  • +zoom;
  • +voiceptt;
  • voice_mic_toggle;
  • demo_pause_toggle;
  • +demo_seek_back;
  • +demo_seek_forward;
  • serverbrowser_toggle;
  • cvar_browser_toggle;
  • demo_browser_toggle;
  • demo_player_toggle.

Q2PRO-X binds participate in the scoped config system. Demo-visual defaults

should not reset binds.

12. Importing an r1q2 cfg: practical order

  1. Start Q2PRO-X 1.2 without the old cfg and confirm it runs.
  2. Copy only the needed binds and mouse values if possible, not the whole old

cfg.

  1. Set cl_mouse_behavior_mode r1q2.
  2. Check sensitivity, m_pitch, m_yaw.
  3. Disable m_accel if the old cfg did not use acceleration.
  4. Tune zoom through cl_zoom_*, not old alias hacks.
  5. Save with q2prox_cfg_save_global.

13. Common problems

Mouse too fast after import

  • check cl_mouse_behavior_mode;
  • check whether m_autosens is enabled;
  • check sensitivity;
  • check m_yaw.

Vertical axis inverted

  • negative m_pitch = invert Y;
  • use a positive value such as 0.022.

Zoom sensitivity feels wrong

  • set cl_zoom_sensitivity_mode auto;
  • temporarily disable m_autosens;
  • check cl_zoom_fov;
  • if you want an old manual feel, use manual mode and

cl_zoom_sensitivity.

Bind rows show ???

??? on a bind row means no key is assigned to that action. It is not a

command error. Assign a key in the menu or through bind.

14. Good baseline

For clean Q2PRO-X:

  • cl_mouse_behavior_mode q2pro;
  • tune sensitivity manually;
  • m_pitch 0.022;
  • m_yaw 0.022;
  • m_accel 0;
  • m_filter 0;
  • m_autosens 0;
  • freelook 1;
  • cl_zoom_sensitivity_mode auto;
  • cl_zoom_time 0;
  • cl_zoom_walk 0.
