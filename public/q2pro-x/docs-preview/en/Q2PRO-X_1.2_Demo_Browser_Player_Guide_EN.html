Q2PRO-X 1.2: demos, Demo Browser, and Demo Player

In 1.2, demo watching became a major client area. This guide explains the

modern demo browser, demo player overlay, MVD/DM2 behavior, analytics, trail

mode, director mode, item timers, and demo-visual cfg.

1. Supported formats

Main formats:

  • .dm2 - normal single-POV demo;
  • .mvd2 - multi-view demo with extra data for MVD playback.

Some features work in both formats, some are MVD2-only:

  • demo browser - both formats;
  • demo player overlay - both formats;
  • pause/seek - both, with different internal implementation;
  • analytics traffic/frags/pickups - full MVD2, DM2 fallback via live POV

sampling;

  • director mode - MVD2;
  • item timers - MVD2.

2. Demo Browser

Path:

  • Options -> Demo Browser;
  • command demo_browser_open;
  • bind demo_browser_toggle.

Main settings:

  • cl_demo_browser_alpha;
  • cl_demo_browser_scale;
  • cl_demo_browser_fullscreen;
  • cl_demo_browser_show_details;
  • cl_demo_browser_row_colors;
  • cl_demo_browser_show_broken;
  • cl_demo_browser_show_packed;
  • cl_demo_browser_remember_tab;
  • cl_demo_browser_last_tab.

The browser uses a central index:

  • demo_index_rebuild - full rescan;
  • demo_index_refresh - incremental refresh.

The index is not part of the release package. It is created locally on the

user's machine.

3. Tabs and organization

The modern demo browser groups demos into working views, for example:

  • All;
  • Favorites;
  • Date;
  • Mod;
  • Map;
  • POV.

Exact visibility depends on the discovered demos and metadata. remember tab

opens the browser on the last used tab next time.

Partial/unreadable demos can be shown or hidden. Packed demos from

engine-visible packs are hidden by default so the user's library is not mixed

with pak contents unless desired.

4. Playlist flow

Demo browser supports selecting multiple demos and playlist behavior.

Useful actions:

  • check demos;
  • play selected queue;
  • jump next / previous;
  • clear playlist.

Binds in Demo Player:

  • demo_playlist_next;
  • demo_playlist_prev;
  • demo_playlist_clear.

When a playlist is active, the demo player overlay shows the related control

cluster.

5. Demo Player Overlay

Path:

  • Options -> Demo Player;
  • command demo_player_open;
  • bind demo_player_toggle.

Key settings:

  • cl_demoplayer_overlay;
  • cl_demoplayer_overlay_alpha;
  • cl_demoplayer_overlay_scale;
  • cl_demoplayer_overlay_autohide_sec;
  • cl_demoplayer_overlay_seek_step_sec;
  • cl_demoplayer_overlay_seek_jump_sec;
  • cl_demoplayer_overlay_y;
  • cl_demoplayer_overlay_show_score;
  • cl_demoplayer_hide_draws;
  • cl_demoplayer_volume;
  • cl_demoplayer_gun;
  • cl_demoplayer_noskins.

The overlay shows playback controls, timeline, mode pills, and popup menus for

several controls.

6. Pause, seek, and keys

Main binds:

  • demo_pause_toggle;
  • +demo_seek_back;
  • +demo_seek_forward;
  • demo_player_toggle;
  • demo_browser_toggle.

Defaults:

  • Space - pause/resume;
  • Left Arrow - seek back;
  • Right Arrow - seek forward.

Seek step and jump are configured separately. For long MVDs, raise jump; for

short duels, keep a smaller step.

7. Demo volume, gun, and skins

cl_demoplayer_volume is a temporary volume override during demo playback.

Normal game volume is restored when playback ends.

cl_demoplayer_gun:

  • show gun;
  • hide gun.

This is a demo-playback override. It does not change normal cl_gun.

cl_demoplayer_noskins:

  • original;
  • no skins.

This is also a playback override. It does not change normal cl_noskins.

8. MVD Director

The MVD-only director helps automatically select POV.

Mode:

  • cl_demoplayer_mvd_director_mode;

Values:

  • off;
  • next frag;
  • quad;
  • penta;
  • leader.

Lead time:

  • cl_demoplayer_mvd_director_lead_sec.

Debug:

  • cl_demoplayer_nextfrag_debug.

next frag uses a pre-scanned frag timeline to switch before the event. A

manual POV override temporarily cools the director down so it does not

immediately take control back.

9. Demo Analytics

Path:

  • Options -> Demo Player -> Demo Analytics.

Main mode:

  • cl_demo_analytics_mode: off / traffic / frags / pickups / all.

Style:

  • cl_demo_analytics_style: overview / world / both.

Time scope:

  • cl_demo_analytics_time_scope: full / elapsed / window;
  • cl_demo_analytics_window_sec.

MVD/DM2:

  • cl_demo_analytics_mvd_autoscan;
  • cl_demo_analytics_dm2_mode.

Density/performance:

  • cl_demo_analytics_sample_ms;
  • cl_demo_analytics_cell_size;
  • cl_demo_analytics_draw_max_cells;
  • cl_demo_analytics_draw_max_events.

Visibility:

  • cl_demo_analytics_overview_alpha;
  • cl_demo_analytics_world_alpha;
  • cl_demo_analytics_world_scale;
  • cl_demo_analytics_show_legend.

Commands:

  • demo_analytics_rescan;
  • demo_analytics_info.

10. Trail mode

Trail mode is enabled when:

  • cl_demo_analytics_world_lifetime_sec > 0.

Instead of an aggregate heatmap, the renderer draws per-sample dots that live

for N seconds and can be connected by lines.

Settings:

  • cl_demo_analytics_trail_stride;
  • cl_demo_analytics_trail_lines;
  • cl_demo_analytics_trail_height_mode;
  • cl_demo_analytics_trail_feet_z;
  • cl_demo_analytics_trail_hover_z;
  • cl_demo_analytics_trail_outline;
  • cl_demo_analytics_trail_outline_alpha;
  • cl_demo_analytics_trail_outline_scale.

trail_height_mode feet draws the trail closer to player feet while following

jumps, falls, and box-to-box movement. hover_z lifts the dots slightly so

they do not clip into the floor.

11. Analytics colors

Analytics colors are edited through:

  • Analytics colors....

Key cvars:

  • cl_demo_analytics_traffic_low_color;
  • cl_demo_analytics_traffic_high_color;
  • cl_demo_analytics_frag_color;
  • cl_demo_analytics_pickup_color;
  • cl_demo_analytics_trail_line_color;
  • cl_demo_analytics_trail_outline_color;
  • cl_demo_analytics_world_adaptive_colors.

The menu uses preset-style color selection, like the model and item timer

editors. Hex values can also be changed through console/cvar browser.

12. Demo Item Timers

Item timers show respawn timers for important items in MVD2.

Master:

  • cl_demo_item_timers_world: off / world only / strip only / both.

World view:

  • translucent ghost item models;
  • countdown labels above the item location;
  • countdown disappears when the item is up.

Strip:

  • demo player strip with item icons;
  • translucent state while the item waits for respawn;
  • timer over the icon;
  • full-color icon when the item is available.

Settings:

  • cl_demo_item_timers_world_alpha;
  • cl_demo_item_timers_world_scale;
  • cl_demo_item_timers_strip_alpha;
  • cl_demo_item_timers_strip_pillarbox_workspace;
  • demo_item_timers_strip_edit;
  • demo_item_timers_strip_reset;
  • demo_item_timers_info.

14. Item timer colors

Item timer colors are edited through:

  • Items colors....

Adaptive mode:

  • cl_demo_item_timers_adaptive_colors.

When adaptive is enabled, colors can inherit from the item-highlight palette.

When disabled, manual per-item text/ring colors are controlled separately.

15. Demo visual cfg

All demo visual settings should save to:

baseq2/q2pro-x/demo_visual/q2pro-x.demo.cfg

This matters for:

  • visibility highlights;
  • model color overrides;
  • analytics;
  • trail;
  • item timers;
  • item timer colors.

The idea: a demo from opentdm, k1, xatrix, or another mod should not

replace your viewing graphics just because playback temporarily entered that

demo's gamedir.

16. Practical scenarios

Just watching demos

  • open Demo Browser;
  • rebuild index once;
  • enable Demo Player overlay;
  • tune cl_demoplayer_volume;
  • choose gun/skins to taste.

Watching an MVD duel with analytics

  • cl_demo_analytics_mode all;
  • cl_demo_analytics_style both;
  • cl_demo_analytics_time_scope elapsed;
  • trail lifetime 3-10 sec;
  • trail_height_mode feet;
  • trail_outline 1.

Studying item control

  • item timers = both;
  • enable armor, megahealth, quad, invuln, power shield;
  • keep weapons off if they clutter the strip;
  • move the strip with demo_item_timers_strip_edit.

Making clean demo capture

  • use the demo-visual cfg;
  • cl_vis_players_mode model;
  • tune player model colors;
  • enable trail outline;
  • enable item timers only when they are useful in-frame.
