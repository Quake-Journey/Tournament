Обновления релиза 1.0 (справочник)

Modern Cvar Browser

`cl_cvar_browser_lang` — язык интерфейса современного браузера cvar. 0 = English, 1 = Русский. Параметр глобальный и сохраняется в Q2PRO-X global config.

`cl_cvar_browser_alpha` — базовая прозрачность современного браузера cvar. В релизе 1.0 итоговая alpha больше не зависит от scr_alpha.

`cl_cvar_browser_scale` — browser-local scale для текста и text-driven chrome. Диапазон 0.5..2.0, по умолчанию 1.0. Предназначен для настройки читабельности самого browser UI, а не всего HUD клиента.

LAGHAX HUD

`cl_laghax_hud_alpha` — отдельная прозрачность LAGHAX HUD. Используется независимо от scr_alpha и следует модели global overlay alpha × OLED UI alpha.

`cl_laghax_hud_show_predict_runtime` — включает read-only runtime-блок weapon predict в LAGHAX HUD. Параметр глобальный, по умолчанию выключен. Нужен для диагностики и не меняет поведение предиктора.

Политика сохранения

Новые параметры 1.0 сохраняются в глобальный Q2PRO-X config и не должны дробиться по mod-local конфигам. Это особенно важно для browser-local scale/alpha/lang и для диагностических параметров LAGHAX HUD.

1. Как читать этот справочник

В справочнике собраны новые cvar Q2PRO-X, а не полный список cvar старого движка Quake II. Для каждой группы важно помнить, что часть настроек живёт в глобальном q2pro-x.cfg, а часть — в mod-local q2pro-x.cfg.

В разделе Сеть и движение важно не путать три разных оси настройки: movement feel, predict backend и step smoothing. Они связаны по ощущениям, но настраиваются независимо.

  • cl_movement_feel_mode = 1 включает R1Q2-like movement feel. Это не "физика R1Q2", а classic command-timing path, который bypasses fixedmove subdivision именно как feel scheduler.
  • cl_predict_move_mode отвечает за modern / legacy predict backend, а cl_step_smoothing_mode — за визуальное feel сглаживания ступенек. Их можно сочетать с movement feel в разных комбинациях.

3. Weapon predicts

В beta 0.97 отдельный новый cvar для hidden-gun fix по-прежнему не нужен: исправление сделано внутри самой логики weapon prediction. Практически это означает, что режимы cl_gun 0 и cl_gun 1 + hand 2 должны работать надёжнее без дополнительной ручной настройки.

Для диагностики анимации view weapon в текущем билде также добавлен отдельный cvar cl_weapon_anim_debug. Он нужен не для обычной игры, а для тех случаев, когда надо сравнить server gunframe, predicted gunframe и реально отрисованный кадр без лишнего шума от cl_predict_debug 2.

4. Display & Capture

cl_altf4_exit

Глобальный cvar Q2PRO-X. По умолчанию 1. Управляет поведением Alt+F4: 1 — игра закрывается обычным путём, 0 — сочетание silently swallowed и не проходит дальше в bind/input path. Настройка хранится в global q2pro-x.cfg и дублируется в Q2PRO-X / Config.

В beta 0.97 в этот раздел добавлены user-facing cvar для управления реальными display modes и для нового pillarbox-сценария. Практически важно разделять два случая: borderless desktop fullscreen и настоящий fullscreen mode switch.

  • desktop fullscreen = yes + vid_resolution = 800x600/1024x768 + vid_desktop_fullscreen_fit = 1 -> centered 4:3-картинка с чёрными полями внутри desktop-native режима.
  • desktop fullscreen = no + vid_resolution = 800x600/1024x768 -> настоящий mode switch дисплея; дальше масштабирование зависит от драйвера и самого монитора.
  • vid_refresh нужен прежде всего для explicit mode selection; при desktop fullscreen он важен как часть выбора подходящего режима, но не переводит монитор в другой desktop timing.

13. Weapon predict diagnostic and policy notes

Сами cvar weapon predict были добавлены раньше, но для 0.97 важно зафиксировать их фактическую политику работы:

  • cl_predict_hyperblaster — теперь сопровождается улучшенным HB handoff/suppression path, чтобы не получать двойной поток локальных и серверных болтов.
  • cl_weapon_anim_debug — печатает server-vs-rendered gunframe timeline и нужен для анализа сложных кейсов.
  • Для machinegun / chaingun / hyperblaster weapon-view animation в shipping path intentionally остаётся server-driven; локально предсказываются не gunframe, а вспомогательные fire-feedback слои.

12.3. Laghax

Для starvation follow-up в `cl_laghax 2` новые пользовательские cvar не добавлялись. Изменение полностью внутреннее. Пользовательский surface остался прежним: `cl_laghax`, `cl_laghax_debug`, `cl_laghax_hud` и существующие weight cvars.

12.4. Предикт оружия / диагностика

Новых основных пользовательских `cl_predict_*` cvar в beta 0.98 не добавлялось. Главное изменение — не расширение набора переключателей, а новая архитектура маршрутизации, phase-gate и handoff внутри уже существующей системы предикта оружия.

12.5. Modern Server Browser

Favorites actions (`Add to Fav` / `Del from Fav`) добавлены как UI-функция modern browser и не вводят новых cvar. Управление идёт через сам overlay и существующую persistence-модель `servers.lst` + `adrN`.
