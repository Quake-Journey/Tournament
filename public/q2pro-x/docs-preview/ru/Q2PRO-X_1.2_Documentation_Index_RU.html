Q2PRO-X 1.2: документация релиза

Этот каталог - пользовательская документация к релизу Q2PRO-X 1.2. Документы идут парами на русском и английском языках и лежат в подпапках ru и en.

Что читать в первую очередь

  1. Q2PRO-X_1.2_Release_Notes_RU.docx - короткая карта релиза 1.2 и рекомендации по обновлению с 1.0 / 1.1 / 1.1A.
  2. Q2PRO-X_1.2_Interface_Menu_Console_Guide_RU.docx - режимы меню, modern renderer, язык, шрифты, scale/alpha и сохранение настроек.
  3. Q2PRO-X_1.2_Controls_Mouse_Zoom_Guide_RU.docx - перенос старых r1q2/q2pro конфигов, mouse behavior, zoom FOV, zoom crosshair.
  4. Q2PRO-X_1.2_Video_Visuals_Guide_RU.docx - video backend, разрешение, render scale, подсветки предметов / игроков / моделей.
  5. Q2PRO-X_1.2_Sound_Guide_RU.docx - OpenAL, HRTF, реверберация и громкости.
  6. Q2PRO-X_1.2_Network_Play_Guide_RU.docx - server browser, laghax, predict, OpenTDM HUD, порт-сканер, русский ввод, автотранслит и /en перевод.
  7. Q2PRO-X_1.2_Demo_Browser_Player_Guide_RU.docx - demo browser, demo player, MVD/DM2, analytics, trail, director, item timers.
  8. Q2PRO-X_1.2_Cvars_Cvar_Browser_Guide_RU.docx - cvars, scopes, save/default commands и встроенный справочник переменных.
  9. Q2PRO-X_1.2_Voice_Chat_Guide_RU.docx - встроенный voice chat, автоподключение, микрофон, PTT/VAD.

Как устроено сохранение настроек

  • GLOBAL настройки сохраняются в baseq2/q2pro-x/q2pro-x.cfg.
  • LOCAL настройки сохраняются в baseq2/q2pro-x/q2pro-x.local.cfg или <gamedir>/q2pro-x/q2pro-x.cfg.
  • Demo visual настройки сохраняются в baseq2/q2pro-x/demo_visual/q2pro-x.demo.cfg.
  • cl_q2prox_cfg_autosave по умолчанию включён; явные команды q2prox_cfg_save* остаются доступны.
  • cl_q2prox_cfg_version 1.2 защищает recommended defaults migration от повторного срабатывания.

Что не входит в этот каталог

Каталог docs не содержит пользовательских конфигов, demo index, crash reports или временных файлов. Это документация релиза, которую можно прикладывать к публичному пакету.
